# Sitio Destacado: La búsqueda avanzada de Google

> Google ofrece la opción de Búsqueda Avanzada que ofrece opciones como: determinar el idioma de los resultados; localizar archivos con cierto formato (por ejemplo, Word, Excel, HTML o PDF); excluir páginas de un sitio Web determinado; determinar qué tan actualizados deben ser los sitios localizados; escoger resultados de un sitio determinado, y no de toda la Web; enfocar la búsqueda a las páginas de un sitio determinado; encontrar todas las páginas que contienen vínculos con un determinado sitio Web; encontrar páginas relacionadas con una determinada página Web.
