**Introducción:**



Zoho es una suite de aplicaciones en línea, la mayoría de ellas gratuitas. Tenemos entre estas últimas Procesador de Texto, Presentador Multimedia, Hoja de Cálculo, Correo electrónico, Bloc de notas y Wiki. También ofrece la posibilidad de cargar y descargar archivos en diferentes formatos.



Para generar los documentos, no se necesita instalar ningún software pues este ya se encuentra alojado en servidores de la Web y para acceder a la suite solo se requiere un navegador de Internet.







**MOSTRAR (PRESENTADOR MULTIMEDIA)**



El Presentador Multimedia de Zoho (Mostrar) cuenta con herramientas básicas para crear presentaciones con diapositivas, textos, enlaces, imágenes, videos y fondos prediseñados. Además, permite importar archivos, con tamaño máximo de 10 MB, en formato ppt, pps, odp y sxi.



  

![imagen](https://eduteka.icesi.edu.co/ediciones/oficce/of-b1_clip_image020.gif)




**Crear nuevo:** opción para crear una nueva Presentación Multimedia. Permite seleccionar el tema o fondo, crear etiquetas y escribir una breve descripción sobre la presentación.





- **Importación:** permite cargar una Presentación Multimedia existente.





- **Mis presentaciones:** las Presentaciones creadas en Zoho se pueden visualizar de tres maneras diferentes:



1. Todo: muestra todas las Presentaciones creadas.
2. Privado: visualiza las presentaciones que no están compartidas.
3. Público: visualiza las presentaciones publicadas o compartidas, que cuentan con URL propia.








- **Presentaciones compartidas: **las Presentaciones compartidas en Zoho pueden visualizarse de cuatro maneras diferentes:


1. Compartido conmigo: esta opción muestra las diapositivas compartidas por otros usuarios de Zoho.
2. Compartido por mi: enseña las presentaciones propias compartidas o publicadas.
3. Presentaciones enviadas a la papelera: muestra la lista de Presentaciones eliminadas. Permite restaurarlas.
4. Nube de etiqueta: muestra las etiquetas creadas y permite listar las Presentaciones asociadas a cada etiqueta.








- **Presentaciones públicas: **Presentaciones publicadas en Zoho que se pueden visualizar en tres diferentes formas:


1. Presentaciones más recientes: muestra las últimas presentaciones creadas y publicadas por todos los usuarios de Zoho. 
2. Presentaciones populares: lista las presentaciones más visitadas por los usuarios de Zoho.
3. Presentaciones disponibles: muestra las presentaciones compartidas o publicadas por otros usuarios de Zoho.






 



# A. MENÚ



![imagen](https://eduteka.icesi.edu.co/ediciones/oficce/of-b1_clip_image022.gif)





- **Guardar: **guarda los cambios realizados a la presentación.

- **Exportar:** convierte la presentación a otros formatos: html, ppt, pps, odp y pdf. 

- **Publicar: **las presentaciones pueden publicarse de 2 maneras:


1. directamente en Internet con una URL propia para que cualquier persona tenga acceso a ellas.
2. en una página Web o en un Blog mediante un código embebido.




- **Compartir: **opción que permite compartir la presentación con otros usuarios en dos modalidades: solo lectura o con permiso para realizar cambios en el contenido.

- **Remoto: **posibilita reproducir una presentación de forma remota por medio de una dirección de Internet (URL), permitiendo a otros usuarios opinar en tiempo real sobre la presentación.

- **Vista:** las diapositivas se pueden visualizar de 3 maneras:

1. Vista normal: muestra la diapositiva y la lista de plantillas creadas.
2. Master View:  muestra las diapositivas con un formato de presentación predefinido.
3. Vista de organizador: muestra las diapositivas en miniatura, aportando una visión general de toda la presentación.




- **Presentación: **ejecuta la presentación y cuando se ha definido previamente que se compartirá, genera una dirección de Internet (URL)

- **Más:** esta opción contiene otras herramientas como: crear un duplicado del archivo, configurar la duración de la presentación, añadir un píe de página a las diapositivas e imprimir la información.



 



# B.SUBMENÚ



![imagen](https://eduteka.icesi.edu.co/ediciones/oficce/of-b1_clip_image024.gif)



Al igual que cualquier Presentador Multimedia, el que ofrece Zoho cuenta con las funciones básicas: formato de fuente, color de letra y de fondo, viñetas, centrar y justificar texto, crear enlaces, reducir e incrementar sangrado, insertar imágenes, caracteres especiales, etc.



 



# C. BARRA LATERAL DERECHA



![imagen](https://eduteka.icesi.edu.co/ediciones/oficce/of-b1_clip_image026.gif)



La barra lateral derecha está organizada en cuatro pestañas, con las siguientes funciones:



![imagen](https://eduteka.icesi.edu.co/ediciones/oficce/of-b1_clip_image028.gif) : inserta objetos o figuras prediseñadas en una diapositiva. Estos objetos están divididos en seis categorías: Formas básicas, Leyendas y estrellas, Bloques y flechas, Diagramas de flujo, Símbolos y ClipArt.



![*](https://eduteka.icesi.edu.co/ediciones/oficce/of-b1_clip_image030.gif) : permite cambiar tanto los colores, como el estilo del fondo de las diapositivas.



![*](https://eduteka.icesi.edu.co/ediciones/oficce/of-b1_clip_image032.gif) : muestra las diferentes versiones que ha tenido la presentación, dando la posibilidad de regresar a una versión anterior.



![imagen](https://eduteka.icesi.edu.co/ediciones/oficce/of-b1_clip_image034.gif) : esta opción informa detalles de la presentación, tales como: nombre, fecha de creación y de última modificación.
