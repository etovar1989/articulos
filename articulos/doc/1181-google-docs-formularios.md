**Introducción:**

“Google Docs” es un servicio gratuito de Google que permite generar, almacenar y administrar documentos en línea, tales como textos, planillas, presentaciones multimedia y formularios. Para crear esos documentos no se necesita instalar ningún software, solo se requiere acceso a un navegador y a una conexión a Internet, preferiblemente de banda ancha. Para utilizar el servicio, basta con tener una cuenta de correo electrónico en Gmail.

**FORMULARIOS**

El Formulario de Google Docs permite recopilar información con diferentes tipos de estructura (test, selección múltiple, comentarios, etc). Los Formularios se pueden publicar como páginas Web o enviarse por correo electrónico para que varias personas diligencien la información solicitada. Esta opción genera automáticamente estadísticas detalladas apoyadas con gráficos.

![imagen](https://eduteka.icesi.edu.co/ediciones/oficce/of1_clip_image002_0001.gif)

 

**A. AÑADIR PREGUNTA**

![imagen](https://eduteka.icesi.edu.co/ediciones/oficce/of1_clip_image004_0001.gif)

Opción que permite seleccionar el tipo de pregunta que se desea incluir en el formulario: test, casillas de verificación, elegir respuesta de una lista, etc (ver imagen siguiente).

![imagen](https://eduteka.icesi.edu.co/ediciones/oficce/of1_clip_image006_0001.gif)

 

**B. ENVIAR FORMULARIO**

![imagen](https://eduteka.icesi.edu.co/ediciones/oficce/of1_clip_image008_0001.gif)

Es posible enviar el formulario a varias direcciones de correo electrónico para que las personas lo diligencien directamente, en el modo lectura del correo. “Google Docs” almacena las respuestas y las procesa para generar estadísticas mediante la Hoja de Cálculo “Google Docs” (ver imagen siguiente).

![imagen](https://eduteka.icesi.edu.co/ediciones/oficce/of1_clip_image010_0001.gif)

 

**C. MOSTRAR ANÁLISIS**

![imagen](https://eduteka.icesi.edu.co/ediciones/oficce/of1_clip_image012_0000.gif)

Este botón muestra el análisis del formulario diligenciado por los usuarios con resumen de las repuestas y gráficos estadísticos. Este análisis de respuestas es el mismo que genera la Hoja de Calculo “Google Docs” (Punto B).

 

**D. MÁS ACCIONES**

![imagen](https://eduteka.icesi.edu.co/ediciones/oficce/of1_clip_image014.gif)

**Insertar: **Opción que genera un código que puede insertarse en un Blog o Página Web, lo que permite mostrar y gestionar un Formulario en otro sitio de Internet (embeber).

- **Editar confirmación:** opción que permite personalizar el mensaje que le debe aparecer a los usuarios una vez diligencien el formulario.

**

E. GUARDAR**

![imagen](https://eduteka.icesi.edu.co/ediciones/oficce/of1_clip_image016.gif)

Aunque el Formulario de “Google Docs” se guarda automáticamente, también es posible almacenar la información haciendo clic en la opción guardar (E).

###  

### F. SALIR

![imagen](https://eduteka.icesi.edu.co/ediciones/oficce/of1_clip_image018.gif)

Esta opción cierra el Formulario y conduce al usuario a la página de inicio de “Google Docs”.
