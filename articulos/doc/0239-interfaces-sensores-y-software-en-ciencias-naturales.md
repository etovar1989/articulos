## **INTERFACES PARA LA RECOLECCIÓN DE DATOS**




¿Qué hacen las interfaces que recolectan datos? ¿Qué clases de interfaces existen y cómo se conectan a un computador?




Las interfaces para la recolección de datos se conectan a los computadores y se les pueden acoplar sensores; así, convierten las lecturas tomadas por estos , en datos que el computador puede usar. Además, mediante circuitos llamados convertidores análogo-digital (A-D), transforman en números las señales variables continuas emitidas por los sensores. Estos números se convierten en valores reales que aparecen en la pantalla, por medio de un programa de computador.




Algunas de las interfaces para la recolección de datos - llamadas interfaces colectoras de datos (data logres) tienen memoria y suministro de energía propios y pueden registrar datos sin estar conectadas a un computador.




## 

**INTERFACES PARA RECOLECCIÓN DE DATOS PARA PUERTO ANÁLOGO**




Algunos computadores, como el Acorn BBC [2], se diseñaron para uso general en los colegios y tienen varios puertos que permiten la conexión con equipos externos. Un puerto particularmente útil es el análogo, el cual permite la conexión de equipos que producen señales análogas [3]. El convertidor A-D en el computador BBC, que viene incorporado al aparato, convierte esas señales a números que los programas pueden mostrar o utilizar para crear gráficos.




Los usuarios de este tipo de computador, encontraron que podían conectar los sensores directamente en el puerto análogo y escribir un programa corto para que se vieran los valores que se reciben de los sensores. Sin embargo, pronto se dieron cuenta que las personas con menos conocimientos técnicos tenían necesidad de algo más que 'enchufar y listo' y fue así cómo se desarrolló la interfaz para puerto análogo [3] en sus diferentes formas. Para computadores más nuevos, es posible comprar un puerto análogo complementario, pero se debe calcular el costo adicional antes de tomar esa decisión además de tener en cuenta que con el ajuste de la tarjeta para el nuevo puerto se restringirá el uso del computador.




Una interfaz estándar para puerto análogo, tendrá conectores en los que se pueden instalar hasta cuatro sensores análogos y hasta dos interruptores digitales. Esto posibilita un rango razonable de sensores pero éstos no se auto identifican (esto es, identificarse por sí mismos); para lograr lecturas confiables, usted tendrá que 'decirle' al software qué sensores están conectados. Las interfaces para puerto análogo son simples, resistentes y ofrecen una buena solución costo-beneficio para esos colegios que todavía tengan en funcionamiento computadores con este tipo de puertos (o que tengan computadores más nuevos a los que le hayan añadido un puerto análogo). Sin embargo, la interfaz únicamente servirá mientras estos computadores estén en servicio, así que es buena idea escoger un fabricante cuyos sensores también se puedan utilizar con interfaces más costosas.




## **INTERFACES PARA RECOLECCIÓN DE DATOS A TRAVÉS DE PUERTOS SERIALES**




Como lo implica el nombre, las interfaces para recolección de datos a través de puertos seriales se conectan en el puerto serial del computador [4]. Casi todos los computadores tienen de una u otra forma este tipo de puerto y algunos tienen hasta dos, que pueden parecer ligeramente diferentes y tener un número distinto de pines [4]. Antes de comprar, asegúrese de que la interfaz de puerto serial que haya escogido tenga cable de conexión y *software* apropiados para los computadores en los que la va a usar. Si desea utilizar la interfaz en varios tipos de computador, entonces, obviamente, tendrá que comprar conectores y software adicionales.




Una ventaja de una interfaz de puerto serial para recolección de datos es que no es especifica para un tipo de computador. Así que si usted tiene varias clases de computadores o planea cambiarse a un sistema diferente en algún momento en el futuro, podrá seguir utilizando la interfaz siempre y cuando el *software* esté todavía disponible. Sin embargo, está interfaz será más costosa que una interfaz para puerto análogo, porque tiene más elementos electrónicos en su interior. Esta interfaz debe permitir que los sensores se auto identifiquen .




Muchas de las interfaces de puerto serial para la recolección de datos también se pueden utilizar sin tener que conectarlas a un computador.




## **RECOLECTORES DE DATOS**




Un recolector de datos es una interfaz autónoma de puertos: serial o USB [5]. Estos tienen su propia memoria y su propio abastecimiento de energía, para permitir la colección y almacenamiento de datos durante un determinado período. Puede conectarse a distintos tipos de computador para transferir datos e instrucciones.




Algunos recolectores de datos se deben programar desde el computador con instrucciones específicas acerca de qué se debe registrar y cuándo hacerlo; luego, se desconectan del computador para transportarlos. Algunos se pueden activar oprimiendo un botón y comenzar así la recolección con cualquier clase de sensor que esté conectado, esto continuará hasta que se le desactive. Algunos tienen pantallas indicadoras para mostrar datos en forma gráfica a medida que estos se recopilan, característica que permite a los estudiantes ver que está ocurriendo (¡y asegurarse de que el aparato está funcionando!). Algunos recolectores pueden almacenar en la memoria, al mismo tiempo, más de un conjunto de datos y todos pueden transferirlos a un computador anfitrión para analizarlos.




Lo que puede ser un problema con estos equipos es la duración de las baterías. Estos recolectores se pueden programar para que registren datos durante semanas, siempre y cuando las baterías funcionen (una regla práctica es pensar que éstas van a durar, la mitad del tiempo que dicen los fabricantes). Es recomendable utilizar un adaptador de energía eléctrica para asegurarse de que, después de un largo periodo de registro, se van a obtener datos que valga la pena analizar.




Es predecible que mientras más funciones tenga un recolector de datos, mayor sea su costo. Vale la pena considerar si usted realmente necesita todas las funciones avanzadas que ofrece un recolector costoso, comparándolo con una interfaz de precio moderado que permite hacer el registro de datos a través de un puerto serial o USB [5].




## **INTERFACES PARA MEDICIÓN Y CONTROL**




Algunos equipos pueden llevar a cabo tanto la recolección de datos como el control de aparatos externos. Puesto que estas funciones requieren una cierta cantidad de energía para activar los aparatos, éstos deben permanecer conectados a la red eléctrica. Tal vez son más costosos que una interfaz directa para registro de datos pero vale la pena hacer una comparición de costos, especialmente si el precio puede compartirse entre varios departamentos con distintas necesidades.




Por ejemplo, en el mismo colegio el departamento de ciencias puede querer utilizar el dispositivo principalmente como interfaz para recolección de datos, mientras que el departamento de tecnología lo va a utilizar para controlar los computadores. Así, ambos departamentos se podrán beneficiar de un ahorro en los costos u obtener más interfaces por su dinero, y podrían también tener la oportunidad de utilizar las funciones adicionales del aparato. Por ejemplo, en la clase de ciencias se podría utilizar este elemento para controlar la temperatura de un recipiente para baño maría mientras se registra el porcentaje de una reacción a esa temperatura; y en la clase de tecnología se podrían controlar los equipos de un invernadero controlado por computador, en respuesta a los valores que reciben de los sensores.




Esta podría ser una solución para usted, pero asegúrese de que el equipo que haya escogido no sacrifique las funciones de medición o control a cambio del simple hecho de que ambas estén disponibles en un mismo elemento.

## **SENSORES **




### **¿Qué tipo de sensores existen y qué hacen?**




Es cierto que el valor de un sistema de recolección de datos depende de la calidad de sus sensores; después de todo, por lo general, la interfaz únicamente es un medio para transferir los datos desde los sensores hacia la pantalla del computador. Los sensores se pueden usar para registrar cambios ambientales en función del tiempo o para registrar el tiempo que transcurre entre un hecho y otro. Los sensores análogos miden variables tales como temperatura, luz, presión o humedad. Los sensores digitales miden si un interruptor está prendido o apagado y generalmente se usan para cronometrar o señalar acontecimientos. Todas las interfaces para el registro de datos aceptan sensores análogos y en su mayoría también aceptan señales digitales.




No hay un estándar único aceptado para todos los sensores puesto que cada interfaz para recolección de datos tiene su propio catálogo de sensores y, desafortunadamente, estos invariablemente son incompatibles con cualquier otro sistema. Muchos sensores se pueden auto identificar, es decir, tienen incorporado un sistema de circuitos que le permite al recolector de datos reconocer qué sensor tiene conectado y convertir sus señales al valor correcto. Es imprescindible contar con un rango adecuado de sensores cuando se va a escoger el sistema que se va a comprar. Es probable que un conjunto de sensores cueste por lo menos tanto como la interfaz misma, por lo tanto se debe tener en cuenta el costo total y no solamente el de la caja de la interfaz.




Todos los sistemas de recolección de datos ofrecen sensores para temperatura y luz, y probablemente no hay mucho para escoger entre ellos. Seguramente podrá cubrir con ellos todas las [actividades](https://eduteka.icesi.edu.co/SensoresSondas.php) que usted planea llevar a cabo [6]. Sin embargo, si desea medir algo más esotérico como el flujo térmico o la densidad del flujo magnético, primero deberá cerciorarse de que el sensor adecuado esté disponible. Además, verifique el rango de funcionamiento del sensor. Un sensor para un rango de temperatura entre 10° C y 60° C no es muy útil para medir el punto de ebullición del agua.




La interfaz para recolección de datos que debe adquirir alguien que se está iniciando podrá complementarse con los siguientes sensores:




### **Equipo de Sensores para Principiantes**






- 2 a 3 para temperatura

- 1 para nivel de luz

- 1 para posición

- 2 para puertas de luz




Además, un departamento podría considerar adquirir uno o más sensores para medir otras variables.




### **Sensores Adicionales **






- sonido

- pulso

- respiración / movimiento del pecho

- pH

- oxígeno

- voltaje

- medidor de tasas de frecuencia

- presión




Usted deberá adquirir sensores que sean lo suficientemente resistentes para aguantar el desgaste normal. Considere cómo y dónde se van a usar; por ejemplo, un sensor simple que se pueda fijar con pegante o cinta adhesiva podría ser más adecuado para sus necesidades que uno diseñado para transportarse manualmente.

## 

**SOFTWARE PARA RECOLECCIÓN DE DATOS **




¿Qué software se necesita para que pueda trabajar con un computador determinado una interfaz para recolección de datos?




Casi todas las interfaces para el recolección de datos tienen su propio software especialmente diseñado, el cual se suministra con la interfaz en forma gratuita o con un costo adicional. Obviamente, se debe verificar que exista un software adecuado para su computador antes de comprar un sistema de recolección de datos y se debe ser muy cauteloso con un fabricante que le diga que la versión que usted requiere la podrá encontrar 'en poco tiempo', ¡esto puede significar cualquier cosa, desde cuatro semanas hasta dieciocho meses!




En el caso especial de las interfaces para puertos análogos, la mayor parte del software diseñado para trabajar con una servirá para cualquiera de las otras. Sin embargo, cada uno de los sensores va a tener tablas de calibración específicas; por lo tanto asegúrese de tener el software que haga lecturas exactas con los sensores que esté utilizando.

## **ESTRATEGIA DE COMPRA**




¿Que se debe tener en cuenta al comprar un sistema de recolección de datos?




Las interfaces para el registro de datos se han desarrollado rápidamente en los últimos cinco años, hasta el punto de que los equipos que se consiguen hoy en día, por lo general, son confiables, fáciles de usar y deben servir durante muchos años. En términos de funcionalidad, entre equipos de categorías equivalentes, no hay mucho para escoger pero de todas maneras se deben verificar las características de lo que obtendrá por su dinero. Por supuesto, usted querrá obtener por su inversión, el mejor equipo posible y hacer el uso más productivo del mismo.




En primer lugar, decida en qué lugar se va a utilizar el equipo. Si solamente lo va a usar en el laboratorio de ciencias, entonces probablemente le servirá una interfaz para puerto serial; si usted quiere llevar a cabo el registro de datos lejos del computador o si el departamento de tecnología participa en el control del computador, debería entonces considerar la compra de un recolector de datos o de una interfaz de medición y control. En cualquier caso, asegúrese de que el software se pueda instalar en los computadores que tenga su colegio en la actualidad y en los que pueda llegar a tener en el futuro.




Usted comprará un sistema de recolección; no solamente una interfaz para recolección, sino también un conjunto de sensores, un cable de conexión y software. Tenga en cuenta el costo de todo eso. Asegúrese de que el sistema escogido tenga el rango (número, cantidad) de sensores que usted requiere; piense en términos de un conjunto básico de los que se usen con más frecuencia para cada una de las interfaces, más uno o dos de los más costosos. La mayoría de los fabricantes ofrecen alguna clase de equipo para principiantes.




Preguntas para hacer:






- ¿Por qué utilizar un sistema de recolección de datos?

- ¿Dónde se usará el registro de datos para mejorar el aprendizaje de las ciencias?

- ¿Qué estilos de enseñanza son los más apropiados para llevar a cabo la recolección de datos ?

- ¿Dónde va a encajar la recolección de datos en el desarrollo de la capacidad de los estudiantes en TICs?

- ¿Cómo se va a entrenar el personal para que aprenda a usar el sistema?

- ¿Qué se tiene en el momento?

- ¿Qué sensores se deben incluir?

- ¿Quién va a organizar el equipo para cada clase y quién hará su mantenimiento?

- ¿Qué provisiones se deben tomar para hacer el mantenimiento del equipo?

- ¿Cómo se va a almacenar el equipo?




## 

**ORGANIZACIÓN DE LOS RECURSOS**




¿Qué factores se deben tener en cuenta en el uso y organización del sistema de recolección de datos?




Como se hace con cualquier otro aparato, el sistema de recolección de datos se debe almacenar de modo seguro y además, se le debe hacer mantenimiento. Hay que tener en cuenta que estos equipos presentan sus propios problemas. Más o menos una docena de sensores, cada uno con 60 cm. de cable, uno o dos cables que sirven de conectores, un suministro de energía y un cable de conexión eléctrica pueden volverse todo un lío. Se necesita una provisión suficiente de bandas elásticas cuando se van a empacar los cables. Las interfaces para el registro de datos con baterías, desechables o recargables, también requieren mucho cuidado. Revise las instrucciones del fabricante acerca de cómo obtener el mayor rendimiento de las baterías. Si usa baterías recargables, piense en cómo asegurarse de que estén totalmente cargadas antes de usarlas.




En el aula, la experiencia ha demostrado que un sistema de recolección de datos se guarda mejor acompañado de una lista de chequeo, que los estudiantes deben consultar al empacarlo. Los estudiantes que no hayan usado antes el equipo pueden beneficiarse con la lista de chequeo. A veces, tal vez durante una sesión introductoria, los estudiantes deberían armar su propio aparato de recolección de datos – esto contribuye de manera importante al desarrollo de sus capacidades en TICs. Otras veces, se deberían tener listas varias actividades para que los estudiantes puedan utilizar al máximo el tiempo de clase realizando investigaciones. En este último caso tal vez necesitará contar con la experiencia de un técnico.




Todo el personal que va a utilizar el equipo va a necesitar tiempo para familiarizarse con este y en especial con el software, que puede tener funciones avanzadas muy útiles que los estudiantes pueden desconocer o no saber manejar y van a necesitar que el maestro se las enseñe.




## 

**CARACTERÍSTICAS QUE SE DEBEN TENER EN CUENTA**




Para las interfaces de recolección de datos






- Buen diseño - resistente, seguro y confiable

- Sensores precisos

- Software de calidad - fácil de utilizar con buenos medios de análisis

- Compatibilidad con los computadores del colegio – los que ya existen y los que se pueden adquirir.

- Sensores que se auto identifican

- Periodo de garantía, acuerdos sobre reparación y devolución

- Una línea telefónica de servicio al cliente




Para recolectores de datos






- Duración de la batería

- Tiempo máximo de registro con baterías

- Memoria Interna - ¿Cuántos conjuntos de datos se pueden almacenar?

- Tamaño y facilidad de transporte
