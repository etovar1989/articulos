**Introducción:**

Zoho es una suite de aplicaciones en línea, la mayoría de ellas gratuitas. Tenemos entre estas últimas Procesador de Texto, Presentador Multimedia, Hoja de Cálculo, Correo electrónico, Bloc de notas y Wiki. También ofrece la posibilidad de cargar y descargar archivos en diferentes formatos.

Para generar los documentos, no se necesita instalar ningún software pues este ya se encuentra alojado en servidores de la Web y para acceder a la suite solo se requiere un navegador de Internet.

**HOJA (HOJA DE CÁLCULO)**

La Hoja de Cálculo de Zoho ofrece funcionalidades básicas para crear planillas con formulas, gráficos, imágenes, funciones, texto con formato, tablas, macros y bordes, entre otras. Además, permite importar archivos tipo xls, sxc, ods, csv y tsv.

![imagen](https://eduteka.icesi.edu.co/ediciones/oficce/of-b3_clip_image002.gif)

**A. MENÚ**

![imagen](https://eduteka.icesi.edu.co/ediciones/oficce/of-b3_clip_image004.gif)

**Nuevo: **genera una Hoja de Cálculo en blanco.

- **Importar: **carga una Hoja de Cálculo existente con formato xls, sxc, ods, csv y tsv.

- **Guardar: **esta opción guarda los cambios realizados al archivo; también permite grabarlo con un nombre nuevo.

- **Imprimir:** imprime el contenido del archivo.

- **Exportar:** convierte la Hoja de Cálculo a otros formatos: xls, ods, sxc, gnumeric, csv, tsv, xml, xhtml, html y pdf.

- **Compartir:** comparte el archivo con otros usuarios en dos modalidades: solo lectura o con autorización para modificar el contenido. Además, permite establecer comunicación vía chat con otros usuarios que estén compartiendo el archivo.

- **Publicar: **la Hoja de Cálculo puede publicarse directamente en un Blog o en una Página Web mediante un código que se genera automáticamente.

- **Más acciones:** esta opción contiene varias herramientas adicionales que permiten crear etiquetas a la Hoja de Cálculo, marcar el archivo como nueva versión, ver el historial de las versiones anteriores y crear plantillas.

- **Macros:** genera y permite visualizar macros. Ofrece también un editor VBA acompañado de un manual de Ayuda para facilitar su utilización.

# B. BOTONES

![imagen](https://eduteka.icesi.edu.co/ediciones/oficce/of-b3_clip_image006.gif)

Los Botones de la Hoja de Cálculo permiten acceder a las funciones que se usan con más frecuencia al manejar una planilla: tipo, color y tamaño de fuente, negrita, cursiva, subrayado, color de fondo, creación de bordes, combinar celdas, sumatoria y funciones matemáticas, gráficos, formatos de moneda, etc.

 

**C. BARRA LATERAL IZQUIERDA**

![imagen](https://eduteka.icesi.edu.co/ediciones/oficce/of-b3_clip_image008.gif)

- **Mis hojas:** muestra la lista de Hojas de Cálculo creadas.

- **My Templates:** muestra la lista de plantillas (formatos preestablecidos) disponibles.

- **Shared with Me: **esta opción permite ver los archivos que se han compartido con otros usuarios de Zoho.

- **Papelera: **lista de archivos eliminados. Ofrece la posibilidad de restaurarlos.
