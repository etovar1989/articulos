# **12 TARJETAS BÁSICAS PARA APRENDER SCRATCH 3.0**




Iniciar a los estudiantes en la programación de computadores, especialmente a los más chicos, es un asunto complejo para muchos docentes. Para atender esta situación, los creadores de [Scratch](https://scratch.mit.edu/) diseñaron una serie de 12 tarjetas para introducir a los más pequeños en el uso básico de Scratch 2.0 (descargue el archivo pdf con las [tarjetas para la versión 2.0](http://scratched.gse.harvard.edu/sites/default/files/scratch2cartascorregidas.pdf)). Por encontrar que aún siguen siendo valiosas estas tarjetas, a continuación publicamos una actualización de estas para la versión 3.0 de Scratch (descargue el archivo pdf con las [12 tarjetas para la versión 3.0](http://eduteka.icesi.edu.co/pdfdir/scratch-3-12-tarjetas.pdf)).
