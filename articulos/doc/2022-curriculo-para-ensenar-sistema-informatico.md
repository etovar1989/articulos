# Currículo para enseñar Sistema Informático

> Sistema Informático se define como el conjunto de elementos que conforman un sistema informático tanto físico como lógico y sus interrelaciones; la función de cada uno y la forma en que intervienen dentro del sistema en el proceso de ejecución de cada tarea. Además, la función que cumplen en los sistemas en un entorno de red.
